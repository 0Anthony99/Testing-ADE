# CalorieTrack

A clean, responsive, client-side daily calorie and macronutrient tracker built with pure HTML, CSS, and JavaScript.

## Features

- **100% Vanilla Tech Stack**: No frameworks, no external libraries, no Tailwind, and no CSS variables.
- **Client-Side Persistence**: Saves all logged meals, history, and custom daily targets directly to browser `localStorage`.
- **Daily Dashboard**: Real-time calorie budget breakdown (consumed vs. goal vs. remaining/overage) and interactive progress bars.
- **Macronutrient Tracking**: Monitors daily grams and percentages for Protein, Carbs, and Fat.
- **Meal Categorization**: Log items under Breakfast, Lunch, Dinner, or Snacks with individual calorie subtotals and delete options.
- **Quick-Add Presets**: One-click logging for popular food and beverage staples.
- **7-Day Trend Chart**: Responsive pure CSS bar chart displaying calorie intake across the past 7 days with click-to-view navigation.
- **Customizable Goals**: Set personal calorie and macronutrient targets or manage/reset stored data.

## Getting Started

No installation, build tools, or server setup required.

Simply open `index.html` in any web browser:

```bash
# On Windows PowerShell:
Start-Process index.html

# Or simply double-click index.html
```
